# scraper_mini
Получение данных из сети в образовательных целях

Ставится задача сбора данных в 4 городах каждый час для проверки, 
где температура выше и её колебания наименьшие.

Для получения данных запустить файл `scraper.py`.
(Понадобится установленный браузер Chrome.)
Данные сохраняются в файл `scraps/scraps.txt` в виде строки
    `дата время город температура`.

Ошибки соединения выносятся в файл `scraps/errors.txt`.
При отсутствии соединения исполнение программы не прерывается, 
часть данных из сбора будет пропущена.

Артефакты сбора данных находятся в файлах:
    `scraps/scraps.txt`, `scraps/scraps1.txt` (начальные данные), `scraps/scraps2.txt`

Результаты обработки полученных данных описаны в файле `scraps/results.txt` и графиками, 
полученными с использованием библиотеки matplotlib.
Отрисовать график можно, запустив файл `scraps/results_view.py`.
